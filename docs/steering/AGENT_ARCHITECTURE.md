# Agent Architecture

## Purpose

Define the roles and responsibilities of AI assistants and future specialized agents.

## Roles

- Product Owner (Ben)
- Chief Architect (ChatGPT)
- Implementation Engineer (current implementation: GitHub Copilot)
- Documentation Engineer (future AI agent)
- Test Engineer (future AI agent)
- Research Engineer (future AI agent)
- Runtime Agents (future system components such as Market Data, Strategy, Risk, Portfolio, Broker, Monitoring, Notification)

## Agent Structure

- AI agents should have a single responsibility.
- Agents operate within defined boundaries and documents.
- New agents are introduced only when there is a clear, repeatable need.
