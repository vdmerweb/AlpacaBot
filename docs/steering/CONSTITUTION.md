# Constitution

## Purpose

Define the core principles that govern AlpacaBot's architecture, engineering practices, and AI collaboration.

## Core Rules

- Broker independence
- Interface-first design
- Dependency inversion
- Testability by design
- Security-first configuration
- Documentation before implementation
- AI serves as assistant, not architect

## Review Expectations

- Every major change is checked against this constitution.
- AI-generated output is validated before acceptance.
- Architecture decisions are recorded and reviewed.
