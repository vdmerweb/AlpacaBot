# Roadmap

## Purpose

Describe the prioritized milestones for AlpacaBot.

## Phase 1

- Project governance and steering documents
- Broker abstraction and Alpaca adapter
- Core platform architecture

## Phase 2

- Market data collection and indicators
- Portfolio and risk management
- Execution engine and order lifecycle

## Phase 3

- Strategy engine and backtesting
- Dashboard and reporting
- AI agent support
