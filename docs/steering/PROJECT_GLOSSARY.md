# Project Glossary

## Purpose

Define shared terminology so all contributors and AI assistants use the same vocabulary.

## Terms

- Agent: A software component or assistant with a specific responsibility.
- Architecture: The static structure of the system and its modules.
- Broker: A trading service provider such as Alpaca or IBKR.
- Adapter: A broker-specific implementation behind a shared interface.
- Market Data: Real-time or historical price and volume information.
- Event: A message that communicates state changes or actions.
- Position: A held security or asset in the portfolio.
- Portfolio: The collection of positions, allocations, and performance metrics.
- Paper Trading: Simulated trading without real capital.
- Live Trading: Trading with real capital and a live account.
- Risk Engine: The component that validates strategy actions against risk rules.
- Scheduler: The component that triggers runtime processes and execution cycles.
- Signal: A trading decision or condition produced by a strategy or indicator.
- Strategy: A set of rules that determines trade entry and exit actions.
- Execution: The process of sending orders to a broker and managing their lifecycle.
- Runtime Agent: A component that operates as part of the running system.
- Development-time Agent: An AI assistant or tool used to build the system.
