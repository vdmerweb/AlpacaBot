# Prompt Library

## Purpose

Provide reusable prompt templates for architecture, design, review, and implementation tasks.

## Architecture Review

```
Review the proposed architecture for AlpacaBot. Identify risks, coupling issues, missing interfaces, and opportunities to improve modularity. Keep the design broker-agnostic and aligned with the current governance documents.
```

## Code Review

```
Review this Python code for correctness, style, readability, and consistency with AlpacaBot coding standards. Highlight any security, architecture, or dependency concerns.
```

## Interface Design

```
Define the public interface for this component. Include method signatures, input/output types, and expected behavior. Keep the interface stable and minimal.
```

## Refactoring

```
Refactor this module for better separation of concerns and maintainability. Preserve existing behavior, add explicit types, and keep the architecture boundaries intact.
```

## Bug Investigation

```
I have a failing test. Help identify the root cause and suggest a minimal fix that preserves the module boundaries and current design.
```

## Test Generation

```
Create pytest test cases for this module. Include normal behavior, edge cases, and failure conditions.
```

## Documentation

```
Write a concise markdown summary for this component, including purpose, responsibilities, and important constraints.
```

## Performance Review

```
Evaluate this design for performance risks. Identify hotspots, expensive operations, and recommendations for efficient execution.
```

## Security Review

```
Review this code or design for security issues. Highlight credential handling, data validation, and exposure risks.
```
