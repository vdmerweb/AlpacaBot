# AlpacaBot Documentation

This repository uses a structured documentation folder to capture vision, architecture, decisions, standards, and operational guidance.

## Primary documents

- `00_Project_Vision.md` - project vision, outcomes, and guiding principles
- `01_Architecture_Blueprint.md` - architecture overview and component structure
- `02_Architecture_Decision_Record.md` - ADR templates and decision logging guidance
- `03_Coding_Standards.md` - coding conventions for Python, tests, and AI collaboration
- `04_AI_Collaboration_Guide.md` - roles, workflows, prompt templates, and review rules for ChatGPT and Copilot
- `05_Project_Roadmap.md` - phased roadmap with milestones
- `06_Module_Designs/` - module-level design documents and detail artifacts
- `07_API_Specifications/` - API contract definitions and specifications
- `08_Testing_Strategy.md` - testing strategy, test categories, and CI guidance
- `09_Deployment_Guide.md` - deployment, environment, and operational guidance

## How to use this folder

- Keep this folder aligned with active development.
- Add modular design docs under `06_Module_Designs/` as new features are defined.
- Add API contracts under `07_API_Specifications/` before implementing public interfaces.
- Treat `04_AI_Collaboration_Guide.md` as the shared playbook for all AI-assisted development.
