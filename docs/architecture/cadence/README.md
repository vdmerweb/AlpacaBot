# Architecture Engineering Cadence

This area stores the operational records that keep the Chief Architect and Implementation Engineer collaboration controlled and resumable.

## Folders

- `active/` — authorized work currently in progress
- `completed/` — execution records for completed work
- `questions/` — open technical or architectural questions
- `learning/` — implementation evidence and lessons for Architecture Baseline v2.0
