# Architecture Documentation

This folder contains the architecture baseline, governance records, and the canonical architectural reference documents for AlpacaBot.

## Key Documents

- `EXECUTIVE_ARCHITECTURE_SUMMARY_v1.md` — North-star summary of architecture direction, governance, and priorities.
- `PHASE_2_ARCHITECTURE_BASELINE_v1.md` — Phase 2 architecture roadmap and approved baseline for Architecture Baseline v1.0.
- `DOMAIN_MODEL.md` — The canonical domain model that defines the platform vocabulary and core concepts.
- `ARCHITECTURE_ONBOARDING_SUMMARY_v1.md` — Onboarding document for a new Chief Architect.
- `docs/architecture/reviews/ARCH-REVIEW-004_Project_Status.md` — Project status review and architecture maturity assessment.

## Record Folders

- `cad/` — Chief Architect Directives for approved architectural instruction.
- `adr/` — Architecture Decision Records documenting approved architecture decisions.
- `reviews/` — Architecture Review Records for completed reviews and assessments.
- `work_packages/` — Work package definitions and scope documents.
- `milestones/` — Milestone definitions and completion criteria.
- `validation/` — Validation artifacts and evidence records.
