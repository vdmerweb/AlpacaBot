# Work Packages

This folder contains Work Package documents describing discrete implementation efforts.

## Historical vs Current Sequence

Historical records may still reference `WP-002` because they were created during earlier architecture planning and review. These records remain intact for traceability and are not renamed or deleted.

The current active cadence sequence is:
- `WP-002_Domain_Model_Architecture_Baseline_v1.md`
- `WP-003_Broker_Capability_Model.md`
- `WP-004` is reserved for the future IBroker Specification and has not been created.

Naming convention:
- `WP-001.md`
- `WP-002_Broker_Abstraction_Design.md` (historical reference)
- `WP-002_Domain_Model_Architecture_Baseline_v1.md` (current active Domain Model package)
- `WP-003_Broker_Capability_Model.md` (current active Broker Capability package)
- `WP-004_IBroker_Specification.md` (future, not yet created)

Each work package should include:
- Title
- Objective
- References
- Deliverables
- Acceptance criteria
