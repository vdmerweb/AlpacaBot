# Chief Architect Directives (CAD)

This folder contains Chief Architect Directives that provide authoritative architectural instruction before implementation.

A CAD is not a decision record; it is a directive that defines the approved architecture direction for a work package.

Naming convention:
- `CAD-001_Title.md`
- `CAD-002_Title.md`

Each CAD should include:
- Title
- Status
- Scope
- Instruction
- References
- Traceability to milestones, work packages, and reviews

Use CADs to:
- define architectural work before implementation
- align the team on approved design direction
- preserve traceability from directive to work package to decision record
