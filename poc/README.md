# POC Workspace

This folder contains experimental, disposable proofs-of-concept used to validate technologies and assumptions.

Guidance

- POC code is intentionally isolated from `src/` or `poc/` production modules.
- Each POC must have a Work Package and use the `POC_REVIEW_TEMPLATE.md` after execution.
- Do not commit POC code until after the POC Review and Product Owner acceptance.
